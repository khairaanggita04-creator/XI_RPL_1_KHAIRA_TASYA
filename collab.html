Langkah-Langkah Collaborators Project GitHub

  • 1. Fork repository utama ke akun GitHub masing-masing.
  • 2. Clone repository hasil fork ke komputer lokal.
  • 3. Buat branch baru untuk setiap fitur ataau perbaikan yang akan dikerjakan.
  • 4. Lakukan perubahan pada kode di branch yang sesuai.
  • 5. Commit perubahan dengan pesan yang jelas dan deskriptif.
  • 6. Push branch ke repository fork di GitHub.
  • 7. Buat pull request dari branch di repository fork ke repository utama.
  • 8. Tim lain akan meninjau pull request dan memberikan masukan atu persetujuan.
  • 9. Jika disetujui, pull request akan di gabungkan ke repository utama.

Note (catatan)

Pastikan untuk selalu melakukan pull dari repository utama sebelum memulai pekerjaan baru, agar tetap sinkron dengan perubahan terbaru dan selalu gunakan pesan Commit yang jelas dan deskriptif untuk memudahkan.
